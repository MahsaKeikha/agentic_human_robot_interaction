# F78 Agentic Human Robot Interaction

Standalone multi-agent reference implementation for human robot interaction research, interaction design, accessibility, trust calibration, safety review, and evaluation.

Agents: [Interaction Research](AGENTS/interaction_research_agent.py), [UX Design](AGENTS/ux_design_agent.py), [Accessibility](AGENTS/accessibility_agent.py), [Trust Calibration](AGENTS/trust_calibration_agent.py), [Safety Review](AGENTS/safety_review_agent.py), [Evaluation](AGENTS/evaluation_agent.py).

Tools are in `TOOLS/`, skills in `SKILLS/`, with orchestration, memory, state, schemas, prompts, config, safety, observability, evals, benchmarks, examples, tests, docs, and CI.

Physical robot control is outside scope.
